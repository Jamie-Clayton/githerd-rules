# GHFM0006: ai-tool-key-in-non-tool-file

The keys name, globs and instructions are the agent-contract vocabulary recognised by CLAUDE.md, AGENTS.md, .cursorrules and *.instructions.md. Finding one in an ordinary harness document usually means tool configuration has leaked into content, or that a document was copied from a tool file. Move the key to the tool file it belongs to.

<!-- begin hand-authored content -->

## Trigger

One of the three agent-contract keys `name`, `globs` or `instructions` appears
in the front matter of a document that is not a tool-configuration file. The
tool files are `CLAUDE.md`, `AGENTS.md`, `.cursorrules` and any
`*.instructions.md`; in those, the same keys are expected and this rule stays
quiet.

## Why the rule exists

Those three keys are the vocabulary agent tooling reads to decide which files a
rule set applies to and what the agent should do with them. When they turn up
in an ordinary harness document it means one of two things, and both are worth
knowing: either a tool file was used as a template and its configuration came
along for the ride, or someone is trying to steer an agent from a document that
no agent reads as configuration. The first is untidy. The second is a rule that
looks like it is in force and is not.

## Fix

1. Decide which file the key belongs to. Agent instructions belong in
   `CLAUDE.md`, `AGENTS.md`, `.cursorrules` or a `*.instructions.md` file.
2. Move the key there, with its value, rather than deleting it. A deleted
   `globs` pattern is a rule set that quietly stopped applying to some files.
3. If the key was copied in by accident and means nothing here, delete it.
4. If you meant a document title rather than an agent contract, use `title`.
   `name` is not a harness front-matter key.

**Quotable fix.** Paste this into a review comment:

> **GHFM0006 (ai-tool-key-in-non-tool-file).** The keys `name`, `globs` and
> `instructions` are agent-tool configuration and are only read from
> `CLAUDE.md`, `AGENTS.md`, `.cursorrules` and `*.instructions.md`. In this
> document the key does nothing. Move it to the tool file it belongs to, or
> delete it. If you meant the document's title, the key is `title`.
